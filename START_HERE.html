CVTara Hostinger setup

Private acceptance build. Not approved for public paid launch yet.

  1. Upload and extract this ZIP in the domain folder containing public_html, not inside public_html.
  2. Enable SSL, PHP 8.3+ and required extensions; create an empty MySQL/MariaDB database.
  3. Open https://YOUR-DOMAIN/install.php and follow the installer. The one-time key is in INSTALL_KEY.txt, outside the web root.
  4. After installation, delete public_html/install.php and INSTALL_KEY.txt. Configure/test email, payments and cron.

See README_HOSTINGER.md for setup and LAUNCH_READINESS.md for remaining acceptance checks.

Payments: Razorpay checkout is included. Cashfree checkout is not implemented; Cashfree Payouts are unverified against a live account.
