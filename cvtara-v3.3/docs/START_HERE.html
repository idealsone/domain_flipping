CVTara v3.3 — Hostinger setup

Private acceptance build. Not approved for public paid launch until the checks in LAUNCH_READINESS.md are done.

  1. Upload and extract this ZIP in the domain folder that contains public_html, not inside it.
  2. Enable SSL, PHP 8.3+ and the required extensions; create an empty MySQL/MariaDB database.
  3. Open https://YOUR-DOMAIN/setup/afsar (private setup link; it stops working after installation). The one-time key is in INSTALL_KEY.txt.
  4. Delete public_html/install.php and INSTALL_KEY.txt. Then follow “First 30 minutes” in README_HOSTINGER.md.

Payments: Razorpay checkout only. Plans and add-ons are managed in Admin → Pricing & add-ons.
