Resume for freshers with no experience

How do I write a resume with no work experience? Replace Work Experience with Projects. List what you built, what it did, and a measurable result. Add internships even if short. Campus roles, coding challenges and certifications count.

Fresher resume order

  1. Name + contact (phone, email, LinkedIn, GitHub)
  2. Summary — one or two sentences: who you are + what role
  3. Skills — tools and languages you can use today
  4. Projects — 2–4, each with a 2-bullet outcome
  5. Internships — even one month counts
  6. Education — degree, CGPA (if ≥ 7.0), institution, year
  7. Certifications, campus roles, competitions (optional)

Writing a project bullet

Use the pattern: Action verb + what you built + what it achieved.
Example: "Built a Python scraper that aggregated 5,000 entries, reducing manual effort by 80%." The number makes the claim defensible.

One page only

Fresher resumes should fit one A4 page. Recruiters spend seconds per CV during campus drives. A tight page that says everything reads faster than two pages that repeat.
